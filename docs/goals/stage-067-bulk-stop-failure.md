# 阶段 67：批量停止失败明细回归

## 目标

固定批量停止任务对已停止、停止成功和业务失败三种结果的统计及摘要，确保前端能
区分跳过项和失败项。

## 范围

- 在 `tests/test_bulk_workflows.py` 覆盖混合结果的批量停止请求。
- 验证 `stopped_count`、`skipped_count`、`failed_count`、`failures` 和摘要。
- 不修改单任务停止接口的 `200 + ok:false` 兼容约定。

## 验收

- “任务未运行”只计入跳过，不计入失败。
- 全量测试、响应式结构烟测、编译检查与 diff 检查通过。
