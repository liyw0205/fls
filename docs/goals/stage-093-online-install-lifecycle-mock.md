# 阶段 93：在线脚本安装生命周期隔离验证

为在线脚本安装的高副作用边界补充专用 mock 回归，固定请求登记、日志跳转以及后台 worker 的成功、失败和停止状态转移。

验收：

- POST `/online-scripts/install/<script_id>` 在目标不存在时初始化 `ONLINE_INSTALL_RUNNING`，安全跳转到对应安装日志页，并确认不启动真实安装线程。
- `install_worker()` 的成功路径收束为 `已完成/0`，失败路径收束为 `失败/1`，停止请求收束为 `已停止/-1`，并清理停止标记。
- 下载、任务导入和安装命令均以 mock 替换；测试不访问网络、不执行真实脚本或安装命令。
- 全量单元测试、响应式烟测、编译检查和差异检查通过。
