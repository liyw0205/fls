# 阶段 65：批量任务表单输入兼容回归

## 目标

固定 `/api/task/bulk-action` 对传统表单请求的兼容行为：去除空白和重复任务 ID，
并仅对归一化后的唯一任务集合执行操作。

## 范围

- 在 `tests/test_bulk_workflows.py` 增加请求级回归测试。
- 验证响应中的 `count`、`updated_count` 与持久化结果。
- 不调整批量接口的运行时协议，除非测试揭示明确缺陷。

## 验收

- 表单 `task_ids` 中的空值、首尾空白和重复项不造成重复写入。
- 全量测试、响应式结构烟测、编译检查与 diff 检查通过。
